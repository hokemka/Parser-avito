# Avito Deal Finder Bot

Telegram-бот на aiogram 3.x: ищет объявления на Авито по запросу пользователя (товар, город, бюджет, пожелания), прогоняет каждое через ИИ-оценщик 1min.ai и выдаёт карточки с оценкой 0–10, вердиктом, разбором состояния, рисков и рекомендуемым торгом. По подписке — мониторинг новых объявлений в фоне.

## Возможности

- **Поиск выгодного**: пошаговый мастер → свежие объявления с Авито → ИИ-оценка лучших кандидатов → карточки с фото, оценкой и кнопкой «Открыть на Авито», подробный разбор по кнопке.
- **Мониторинг**: фоновая проверка Авито по каждому запросу с интервалом тарифа, новые объявления с оценкой не ниже порога прилетают пользователю автоматически.
- **Подписки и тарифы**: покупка за Telegram Stars, CryptoBot (фиат-счёт в рублях или крипто-актив), с баланса. Баланс пополняется теми же способами.
- **Админ-панель**: статистика, рассылка (любой контент, форматирование, кнопки-ссылки, подтверждение, отчёт), пользователи (поиск по ID/username, экспорт txt, баланс, бан, выдача/снятие подписки), тарифы (CRUD), оплата (включение методов, токен CryptoBot, курсы), парсер и ИИ (модель, анализ фото, прокси, тесты).
- **Премиум-эмодзи** в сообщениях и на кнопках, отключаются одной настройкой.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp settings.example.ini settings.ini
```

Заполните `settings.ini`:

| Секция | Ключ | Описание |
| --- | --- | --- |
| `bot` | `token` | токен бота от @BotFather |
| `bot` | `admin_ids` | ID администраторов через запятую |
| `bot` | `premium_emoji` | `true` — использовать премиум-эмодзи (бот должен иметь право на кастомные эмодзи), иначе `false` |
| `avito` | `proxy` | прокси для Авито (`http://user:pass@host:port` или `socks5://…`). С дата-центровых IP Авито отдаёт «Доступ ограничен», нужны мобильные/резидентные прокси |
| `ai` | `api_key` | ключ API 1min.ai |
| `ai` | `model` | модель, например `gpt-4o-mini`, `gpt-4o`, `claude-sonnet-4-20250514`, `gemini-2.5-flash` |
| `payments` | `cryptobot_token` | токен приложения Crypto Pay (можно задать в админке) |

Запуск:

```bash
python main.py
```

Настройки из админ-панели сохраняются в базе и имеют приоритет над `settings.ini`.

## Структура

```
main.py                 точка входа
config.py               чтение settings.ini
tgbot/handlers          пользовательские сценарии и админка
tgbot/fsm               состояния мастеров
tgbot/keyboards         инлайн и reply-клавиатуры
tgbot/middlewares       сессия БД, регистрация пользователя, антифлуд
tgbot/services          Авито, 1min.ai, CryptoBot, подписки, платежи, мониторинг
tgbot/database          модели SQLAlchemy и подключение (SQLite)
tgbot/utils             эмодзи, тексты, карточки, форматирование
tests                   тесты парсеров и бизнес-логики
```
