# Avito Deal Finder Bot

Telegram-бот на aiogram 3.x: ищет объявления на Авито по запросу пользователя (товар, город, бюджет, пожелания), прогоняет каждое через ИИ-оценщик 1min.ai и выдаёт карточки с оценкой 0–10, вердиктом, разбором состояния, рисков и рекомендуемым торгом. По подписке — мониторинг новых объявлений в фоне.

## Возможности

- **Поиск выгодного**: пошаговый мастер → свежие объявления с Авито → ИИ-оценка лучших кандидатов → карточки с фото, оценкой и кнопкой «Открыть на Авито», подробный разбор по кнопке.
- **Мониторинг**: фоновая проверка Авито по каждому запросу с интервалом тарифа, новые объявления с оценкой не ниже порога прилетают пользователю автоматически.
- **Подписки и тарифы**: покупка за Telegram Stars, CryptoBot (фиат-счёт в рублях или крипто-актив), с баланса. Баланс пополняется теми же способами.
- **Админ-панель**: статистика, рассылка (любой контент, форматирование, кнопки-ссылки, подтверждение, отчёт), пользователи (поиск по ID/username, экспорт txt, баланс, бан, выдача/снятие подписки), тарифы (CRUD), оплата (включение методов, токен CryptoBot, курсы), парсер и ИИ (модель, анализ фото, прокси, тесты).
- **Премиум-эмодзи** в сообщениях и на кнопках, отключаются одной настройкой. Кнопки цветные: синие — основные действия, зелёные — оплата и подтверждение, красные — отмена, удаление и бан.
- Кнопка «Админ-панель» появляется в меню только у администраторов из `admin_ids`.

## Как устроен парсер Авито

Официального API у Авито нет, поэтому бот работает через собственный слой поверх браузера [Camoufox](https://camoufox.com) (антидетект-сборка Firefox с Playwright-совместимым API):

1. Браузер открывает страницу выдачи `https://www.avito.ru/{город}?q=…&s=104&pmin=…&pmax=…` (сортировка по дате) с постоянным профилем, прокси и человеческими паузами.
2. Объявления читаются из встроенного состояния страницы (`window.__initialData__` или `<script data-mfe-state>`), а если формат страницы поменялся — из DOM по атрибутам `data-marker`.
3. Для ИИ-оценки открывается страница объявления: описание, характеристики, продавец, фото.
4. Блокировки («Доступ ограничен: проблема с IP», 403/429, капча) распознаются автоматически: парсер уходит в паузу, админы получают уведомление, в админке есть перезапуск браузера и смена прокси на лету.

С дата-центровых IP Авито почти всегда отдаёт блокировку — нужен мобильный или резидентный прокси (`[avito] proxy`). Для отладки без Camoufox можно переключить `engine = chromium` (обычный Playwright Chromium).

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m camoufox fetch
cp settings.example.ini settings.ini
```

На Linux-сервере без дисплея Camoufox работает в `headless = true`; если сайт капризничает на headless, поставьте `xvfb` и укажите `headless = virtual`.

Заполните `settings.ini`:

| Секция | Ключ | Описание |
| --- | --- | --- |
| `bot` | `token` | токен бота от @BotFather |
| `bot` | `admin_ids` | ID администраторов через запятую |
| `bot` | `premium_emoji` | `true` — использовать премиум-эмодзи (бот должен иметь право на кастомные эмодзи), иначе `false` |
| `avito` | `engine` | `camoufox` (боевой режим) или `chromium` (отладка через Playwright Chromium) |
| `avito` | `headless` | `true`, `false` или `virtual` (через xvfb) |
| `avito` | `proxy` | прокси для Авито (`http://user:pass@host:port` или `socks5://…`). С дата-центровых IP Авито отдаёт «Доступ ограничен», нужны мобильные/резидентные прокси |
| `avito` | `profile_dir` | папка постоянного профиля браузера (куки переживают перезапуск) |
| `avito` | `request_delay` | пауза между запросами к Авито в секундах (к ней добавляется случайный джиттер) |
| `ai` | `api_key` | ключ API 1min.ai |
| `ai` | `model` | текстовая модель 1min.ai, по умолчанию бесплатная `qwen3-8b`; варианты `qwen3.7-flash`, `gpt-4o-mini`, `gpt-4.1`, `claude-sonnet-4-6` |
| `ai` | `vision_model` | модель для объявлений с фото, по умолчанию `qwen3-vl-flash` (проверено: видит фото, дёшево); `qwen3-8b` фото не понимает |
| `payments` | `cryptobot_token` | токен приложения Crypto Pay (можно задать в админке) |

Запуск:

```bash
python main.py
```

Настройки из админ-панели сохраняются в базе и имеют приоритет над `settings.ini`.

```
main.py                 точка входа
config.py               чтение settings.ini

tgbot/fsm               состояния мастеров
tgbot/keyboards         инлайн и reply-клавиатуры
tgbot/middlewares       сессия БД, регистрация пользователя, антифлуд
tgbot/services          Авито, 1min.ai, CryptoBot, подписки, платежи, мониторинг
tgbot/database          модели SQLAlchemy и подключение (SQLite)
tgbot/utils             эмодзи, тексты, карточки, форматирование
tests                   тесты парсеров и бизнес-логики
```
